# Project Chimera – High-Level Vision & Constraints

## Vision
Build a spec-driven, governed factory for autonomous AI influencers capable of:
- Perception via MCP Resources
- Reasoning & task orchestration via FastRender Swarm (Planner → Worker → Judge)
- Multimodal content generation (text, image, video)
- Platform-agnostic social engagement
- Economic agency via Coinbase AgentKit non-custodial wallets

Goal: Enable a single human Super-Orchestrator to manage thousands of agents with minimal intervention.

## Core Constraints
- Spec as sole source of truth: no code or implementation before ratified specs
- Traceability: Tenx MCP Sense connected at all times
- No vibe coding: all development follows SDD + TDD
- Governance & safety: HITL on low-confidence/risky content & financial actions
- Scalability: horizontal Worker pool, support 1,000+ concurrent agents
- Regulatory: self-disclosure, platform-native AI labeling
- Cost control: Resource Governor to prevent runaway inference/media costs
- Multi-tenancy: strict data isolation between clients/brands

## Glossary (partial)
- Chimera Agent: Sovereign entity with unique persona (SOUL.md), memory, wallet
- MCP: Universal interface for Resources/Tools/Prompts
- FastRender Swarm: Planner (decomposes), Worker (executes), Judge (validates + OCC)
- OCC: Optimistic Concurrency Control for state consistency
